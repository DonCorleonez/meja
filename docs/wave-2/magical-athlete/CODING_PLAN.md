## MA1 — Verified rules engine
- Inventory both track faces, exact coordinates/special spaces and finish rules, roster and power timing/optional targets, point awards (first/second per race, special awards), initial setup and turn order. Data-driven track/racer/award schemas, unique IDs, provenance. Verify draft distribution and team selection/reveal for four heats; special 2-player mode with multiple racers and 3-player adjustments if applicable; used racer cannot be reused except explicit powers. 
- Implement types.ts (Config, MatchState, Racer, Track, Ability, PendingChoice, Event); setup.ts; legal.ts; reducer split draft.ts, race.ts, movement.ts, powers.ts, scoring.ts, scheduler.ts; view.ts and rng.ts. State phases recruit/select/reveal/racing/choice/award/next/finished. Explicit active racer and controller, pending decisions, event queue and causality IDs; RNG consumes only accepted roll/reroll actions. Main movement vs secondary movement vs warp must be distinct. Passing, stopped co-location, tripped state, skip next main move, recovery, special track arrows/spaces, eliminated/finished status, turn changes, awards, race finish and no second finisher edge. 
- Build deterministic ability registry keyed by verified racer ID; typed trigger phase/condition/target/effect; use custom pure resolvers for exceptional mechanics rather than arbitrary eval. Effect scheduler orders track effects, active player, clockwise others per verified source; simultaneous movement groups atomic, no stop trigger if updated rule excludes it; distinguish roll finalized vs reroll event. Mandatory vs optional effects, choices routed to correct controller, finite/loop handling exactly per rulebook, skipped/extra turns and multiple racers order. Never silently truncate valid effects. Golden tests for every racer alone and interactions e.g. Magician reroll, Skipper/Inchworm, Copycat/ability mimic, Banana passing, M.O.U.T.H. elimination, coach modifiers, warp vs pass, simultaneous arrival, race end/award. Verify names/effects and exact exception cases rather than treating examples as complete rules. Property tests pairwise/three-way powers, chain reactions, no illegal moves and deterministic replay. 
- Match scoring: exact award values and tie handling, per-race contributions and four-race reset/used roster; 2–6 supported, including 2-player multiple racers. Every official power and both tracks verified before release claim.
## MA2 — Authentic design
Playful retro fantasy sports carnival; winding physical track topology on each side is focal, original hand-drawn inspired SVG racer silhouettes, colored cards with concise paraphrased power and timing icons, wooden-piece feel without copied illustration. Draft display, team lineup, race selection/reveal, prominent die, track positions/stack for shared spaces, ability queue/choice sheet, score and heat progress. Responsive viewport pan/zoom and fit-to-track option; touch/keyboard alternatives; privacy where rules require secret selection. Use official reference images for comparison only. 
## MA3 — Immersion
Race animation step/warp/trip/stand, dice roll and ability triggers, original announcer/sfx, clear causality log and resolve important choices before continuing; speed controls cannot change outcome. Tutorial first race + ability tooltips, optional public spectator board, heat awards/results/rematch. Mid-effect autosave resumes consistent state without duplicate action; reduced motion.
## MA4 — AI
Easy random legal recruit/select/optional powers; Normal ability-aware matchup and track utility; Hard seeded bounded rollouts over roster/remaining heats and public opponents, hidden selection sampled if required. Future RNG and secret picks never accessible. Bench seat-rotated 200+ per matchup and 2–6 distribution; win/award rates, matchup/power coverage, p95 performance, no illegal choices. AI not allowed to modify luck. 
## MA5 — RC
All verified athletes, tracks, powers, race rules and 2–6 modes; mixed AI/human and all-bot demo, complete game 4 heats under replay, full QA, review before hub registration. Second Wind separate future scope.
